小宇宙播客字幕

“播客字幕”用本机的小宇宙命令行 xyz 抓取。没有的话，按 的说明安装并登录：

uv tool install git+https://github.com/lima1217/xiaoyuzhou
xyz send-code <手机号>
xyz login <手机号> <验证码>

装好后重新打开设置即可看到状态，无需重启服务。

YouTube 字幕

uv tool install --reinstall -e .
